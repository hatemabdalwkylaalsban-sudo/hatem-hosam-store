# 🛒 متجر حاتم وحسام الإلكتروني

مشروع مقرر تطوير تطبيقات الويب + مشروع التخرج (أمن سيبراني)

---

## 👥 إعداد الطلاب

- حاتم الصبان
- حسام مرزح

---

## 🎯 وصف المشروع

متجر إلكتروني متكامل يتيح للمستخدمين:
- تصفح المنتجات والبحث والفلترة
- إضافة المنتجات للسلة وإتمام الطلبات
- إدارة الحساب الشخصي وتتبع الطلبات

وللأدمن:
- لوحة تحكم بإحصائيات كاملة
- إدارة المنتجات والتصنيفات (CRUD كامل)
- إدارة الطلبات والمستخدمين

---

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| PHP 8.2 | لغة البرمجة الخلفية |
| MySQL | قاعدة البيانات |
| PDO | الاتصال الآمن بقاعدة البيانات |
| Bootstrap 5 RTL | التصميم المتجاوب |
| Font Awesome | الأيقونات |
| Cairo Font | الخط العربي |

---

## 🔐 ميزات الأمان

- ✅ حماية كلمات المرور: password_hash() + password_verify()
- ✅ منع SQL Injection: Prepared Statements + PDO
- ✅ منع XSS: htmlspecialchars() لكل مخرجات المستخدم
- ✅ التحقق من الصلاحيات: require_login() + require_admin()
- ✅ CSRF Protection: توليد والتحقق من tokens
- ✅ التحقق من المدخلات: Validation من جهة الخادم
